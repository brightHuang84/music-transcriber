# 听音识谱

把一首歌放进窗口，程序会在**你自己的电脑**上：

1. 把歌分成四条音轨：人声、鼓、贝斯、其他乐器，并且可以单独听。
2. 给人声、贝斯、其他乐器识别出音符（音高、什么时候开始、持续多久、力度），画成钢琴卷帘，并标出 C4、E4 这样的音名和唱名。
3. 给鼓识别底鼓、军鼓、踩镲，画成对齐拍子的格子。
4. 估计整首歌的速度（BPM）、拍子和小节第一拍。能判断的话，也会标出简单的大和弦 / 小和弦。
5. 导出每一轨的 MIDI、合并后的 MIDI，以及分开的音频。

歌曲不会上传到网上。窗口里会显示分析进度；分析在后台进行，窗口可以继续操作。

## Ubuntu（推荐）

适用 Ubuntu 24.04、26.04 这类桌面系统（GNOME）。不需要自己安装或挑选 Python。安装脚本会用 [uv](https://docs.astral.sh/uv/) 下载 Python 3.12，系统自带的更新版本不会被拿来跑这个程序。

在这个文件夹里打开终端，运行：

```bash
chmod +x install.sh uninstall.sh
./install.sh
```

脚本会请你输入开机密码，用来安装 ffmpeg、中文字体和窗口所需的系统库。它用 uv 下载 Python 3.12 并创建虚拟环境。这个环境里没有 pip，安装包由 `uv pip` 完成。如果上次安装中途停了（例如停在 `No module named pip`），不用删文件夹，再运行一次 `./install.sh` 就会接着装。

装完后：

1. 按 Super 键（许多键盘上标着 Windows 标志）。
2. 搜索「听音识谱」。
3. 点击图标。程序会以自己的窗口打开，不会打开浏览器，也不会留下终端窗口。

想卸掉菜单图标和虚拟环境时，运行：

```bash
./uninstall.sh
```

项目文件夹还在。不再需要这个软件时，把整个文件夹删掉即可。

有 NVIDIA 显卡，并且安装时能运行 `nvidia-smi`，会安装 CUDA 版 PyTorch，分离音轨时优先用显卡。没有显卡，或显卡版没有装上，就用 CPU，结果一样，只是更慢。窗口本身用软件绘制，这和分离音轨用不用显卡是两回事。

打不开时，把这个文件发给懂电脑的朋友：`~/.local/share/tingyin-shipu/app.log`。

## Windows 和 macOS

这两边仍然可以用浏览器打开，不是 Ubuntu 上的独立窗口。

**Windows：** 安装 [Python 3.12](https://www.python.org/downloads/)（勾选 Add python.exe to PATH）和 ffmpeg（PowerShell 里运行 `winget install Gyan.FFmpeg`），然后双击 `start.bat`。不要关掉那个黑色窗口。

**macOS：** 安装 Python 3.12 和 ffmpeg（`brew install python@3.12 ffmpeg`），然后运行 `./start.sh`。不要关掉那个终端窗口。

不要用 Python 3.13 或更新的版本。Ubuntu 用户不要运行 `start.sh`，那个脚本会提示你改用 `install.sh`。

## 怎么用

1. 把 mp3、wav、m4a 或 flac 拖进窗口，或点击「选择歌曲」。
2. 等待进度走完。分离音轨最慢。一首 3 分钟左右的歌，在没有独立显卡的电脑上常常要几分钟到十几分钟。进度条和步骤会留在窗口里。
3. 完成后：
   - 点「人声 / 鼓 / 贝斯 / 其他乐器」切换你正在看的乐器。
   - 上传前可以选「精细」或「快速」。精细会多拆出钢琴和吉他，第一次大约再下载 55MB；快速只分人声、鼓、贝斯和其他乐器，鼓和贝斯通常更干净，模型大约 84MB（分析过歌的电脑一般已经有了）。两种方式一首 3 分钟的歌耗时差不多。小提琴、大提琴、管乐、铜管和合成器都会留在「其他乐器」里。
   - 「原曲」边听整首歌边看当前乐器；「只听当前乐器」只放这一轨；「有声音的轨一起」把有声音的音轨叠回去。几乎没声音的乐器按钮会变灰。
   - 「播放」会变成「暂停」。也可以点「停止」，或按空格键播放 / 暂停。拖动进度条，或在格子上点击，可以跳到那个时间。
   - 播放时画面会跟着走，播放头一直留在看得见的地方。钢琴卷帘和鼓的格子都会跟着，横着走，格子比窗口高时也会跟着上下走。用滚轮或滚动条自己移动画面之后就不再自动跟着，点「跟随」可以恢复。
   - 钢琴卷帘上的字就是音名。左边 C4 的 4 表示八度，数字越大音越高。旁边也会标唱名。
   - 鼓的每一行是一种鼓：底鼓、军鼓、闭镲、开镲、叮叮镲、吊镲，以及高音、中音、落地通鼓。格子按十六分音符对齐。竖线是拍，颜色更深的是小节第一拍。
4. 右侧可以下载当前音轨、当前 MIDI、全部 MIDI，或打包下载。保存时会弹出「保存文件」窗口。

没有现成歌曲时，可以点「先分析一段 4 秒示例」。那是程序生成的小旋律，用来熟悉界面，同样会走完整分析。

分析过程中不要关掉听音识谱窗口。关掉窗口，这次分析就停了。

## 结果可以怎么理解

- **C4** 是中央 C。唱名 do re mi fa sol la si 对应 C D E F G A B。
- 速度 **120 BPM** 表示一分钟大约 120 拍。
- 调性和和弦是自动估计的，只作参考。程序只标大和弦和小和弦。
- 自动识谱会有错音、漏音，八度也可能偏高或偏低。把它当成学习的起点，对照着耳朵听。

MIDI 可以用 [MuseScore](https://musescore.org/)（免费）打开，看更接近五线谱的样子。音轨名称是英文：Vocals、Drums、Bass、Guitar、Piano、Other。音色用的是通用 MIDI：人声 53（Voice Oohs）、钢琴 0、吉他 25（钢弦吉他）、贝斯 33、其他乐器 48（弦乐合奏）、鼓在第 10 通道。没有单独的小提琴或大提琴音轨，所以不会写成 40 或 42。

## 它在背后做了什么

窗口是 Qt 6 画出来的。里面用 Qt WebEngine（同一套 Chromium 引擎）显示原来的界面，所以钢琴卷帘、鼓点和播放都还在，但地址栏和浏览器标签都没有。分析服务只监听本机 `127.0.0.1`，随窗口一起启动，随窗口一起退出。

- 音轨分离：[Demucs](https://github.com/facebookresearch/demucs)。**快速**用 **htdemucs**（人声、鼓、贝斯、其他，约 84MB）。**精细**用 **htdemucs_6s**（再加吉他和钢琴，约 55MB）。两种都在 CPU 上跑。比较过更新的 BS-RoFormer / MelBand-RoFormer：公开、能自动下载的那些模型几乎都是「人声 / 伴奏」，并不多拆小提琴、管乐或铜管，而且权重大、更慢，所以没有加进程序。
- 音符识别：[Spotify Basic Pitch](https://github.com/spotify/basic-pitch)（ONNX，不需要安装 TensorFlow）。
- 鼓点：[ADTOF](https://github.com/xavriley/ADTOF-pytorch) 的鼓声模型，按底鼓、军鼓、踩镲、通鼓、镲片各自的阈值听每一次响，不是只留最响的那一种。然后再看声音本身：很低又不吵的归到底鼓或通鼓，中频又噪的才留作军鼓，真正有高频才分成闭镲、开镲、叮叮镲或吊镲。同一次可以同时留下底鼓和踩镲，或者军鼓和吊镲。同一次只会留一只通鼓，也不会把底鼓再标成落地通鼓。通鼓的音高看低音里最清楚的那个频率，避免把很低的鼓标成高通鼓。写进 MIDI 时，同时敲响的几种鼓会写成几个音。模型装不上时，会退回只标底鼓、军鼓和闭镲。

第一次用某种分轨方式时，会下载对应的 Demucs 模型（快速约 84MB，精细约 55MB）。窗口里的进度条会显示已经下了多少。下过一次就留在这台电脑上。

## 常见问题

**安装停在 `No module named pip`，或中途报错停了。**  
再运行一次 `./install.sh`。脚本会用 `uv pip` 继续安装，不需要自己安装 pip，也不需要删掉 `.venv`。

**应用程序菜单里找不到图标。**  
再运行一次 `./install.sh`。然后注销一次，或按 Super 再搜索「听音识谱」。

**提示找不到 ffmpeg。**  
再运行 `./install.sh`。它会用系统包管理器安装 ffmpeg。

**一直停在「分离音轨」。**  
这是正常的，CPU 上这一步很慢。请让窗口开着。第一次失败常常是因为没联网，模型没下载下来。看 `~/.local/share/tingyin-shipu/app.log`。

**提示内存不够。**  
关掉其他占内存的软件，或把歌曲剪到 1–3 分钟再试。

**人声、钢琴或吉他那一轨是灰的。**  
变灰表示这一轨几乎没有声音。纯音乐常常没有人声。快速模式不会单独分出钢琴和吉他，它们在「其他乐器」里。精细模式的钢琴分离是 Demucs 的实验音轨，有时会串到别的轨。小提琴、大提琴、管乐和合成器目前都在「其他乐器」。

**鼓点或和弦和我听到的不一样。**  
没有镲片的歌不会硬标出踩镲。底鼓和踩镲、军鼓和吊镲如果真的一起响，会同时标出来。军鼓和通鼓如果都很低沉，仍可能换错。很密的闭镲、爵士鼓和电子鼓也容易标错。和弦遇到七和弦、转位、很多乐器一起响时会偏。旋律相对更可信，但仍然不是人工记谱。

**窗口里出现错误提示。**  
提示是写给人看的。按提示换文件、重开窗口，或把日志文件发给懂电脑的朋友。

## 给想改代码的人

```bash
export UV_PYTHON_PREFERENCE=only-managed
uv python install 3.12
uv venv --python 3.12 .venv
# uv 创建的环境没有 pip，用 uv pip，不要用 python -m pip
uv pip install --python .venv/bin/python -r requirements-dev.txt
uv pip install --python .venv/bin/python "basic-pitch==0.4.0" --no-deps
uv pip install --python .venv/bin/python -r requirements-desktop.txt
# 按 install.sh 里的方式装好 torch / torchaudio（有 nvidia-smi 用 CUDA，否则用 CPU 轮子）
.venv/bin/python -m pytest tests
.venv/bin/python -m app.desktop
```

`tests/test_smoke.py` 会用一段 4 秒合成音乐跑通快速模式的分离、识谱、鼓点、MIDI。第一次会下载模型。`tests/test_instruments.py` 在装了 FluidSynth 和通用 MIDI 音源时，再用精细模式检查钢琴、小提琴和吉他；没装就跳过，不影响安装。

## 已知限制

- 在 Ubuntu 24.04（X11）上打开过窗口。Ubuntu 26.04 的 GNOME / Wayland 用的是同一套 Qt 窗口，但那套桌面没有在这里逐项点过。
- 窗口绘制关掉了 Chromium 的 GPU 合成，避免有些机器上窗口一片空白。分离音轨仍然会在有 NVIDIA 显卡时使用 CUDA。
- 没有提供 AppImage 或 deb 安装包。安装方式是 `./install.sh`。
- 默认假设 4/4 拍。三拍子的歌，小节线可能对不齐。
- 不识别歌词，也不生成五线谱图片（MIDI 可以交给 MuseScore）。
- 一首歌最长接受约 10 分钟，文件最大约 120MB。
- 鼓点用 ADTOF 的多标签结果，再用声音高低和噪声修正。同一次敲击可以有几种鼓，但不会把同一次底鼓标成底鼓加落地通鼓。没有镲的段落不会标成镲，很低沉的军鼓和通鼓仍可能换错。
- 和弦只估计大三和弦和小三和弦。
- 精细模式能单独分出钢琴和吉他，分不准时音符会串到别的轨。小提琴、大提琴、管乐、铜管、合成器没有单独音轨，记在「其他乐器」上，音色是弦乐合奏。
- 快速模式的鼓和贝斯通常比精细模式更干净。要鼓谱、又不需要单独的钢琴轨时，用快速。
- 分析依赖锁在 Python 3.12。安装脚本会自己下载这个版本。
